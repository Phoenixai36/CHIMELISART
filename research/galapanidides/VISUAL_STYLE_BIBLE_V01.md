# GALAPANÍDIDES — Visual Style Bible v0.1

## Source-derived traits

The photographed pencil edition repeatedly combines human faces, eyes, organic/tubular structures, circular/spiral motifs, geometric patterning, architectural silhouettes and large-scale environmental compositions.

## Non-negotiable style rules

1. Graphite/pencil remains the visual DNA.
2. Line density is meaningful: do not flatten every drawing into uniform outlines.
3. Imperfection is preserved; avoid sterile vector-cleaning.
4. Organic and geometric structures can occupy the same object.
5. Faces can function as architecture, environment, identity marker or symbolic surface.
6. The gutter of the physical spread may become a dimensional seam rather than being erased conceptually.
7. Scale must be ambiguous where the source is ambiguous.
8. Repetition should create visual grammar, not procedural wallpaper.

## Camera language

- Prefer slow lateral/diagonal discovery.
- Allow compositions to be read before the camera approaches them.
- Use foreground occlusion as a deliberate depth cue.
- Avoid constant game-camera centering.
- Permit moments where the environment dominates the screen.

## Material language

### Pencil substrate

- monochrome graphite base;
- paper grain retained where useful;
- soft tonal gradients from hand pressure;
- selective high-contrast graphite marks;
- no automatic cel-shading.

### Dimensional anomaly

The anomaly should alter the relationship between layers rather than simply add a colored glow. Candidate effects:

- parallax phase offset;
- local line displacement;
- subtle temporal echo;
- depth inversion;
- incomplete geometry;
- portal-edge distortion.

## Character rendering

Characters should remain visually integrated with the environment. Avoid a generic character-sprite aesthetic. Human appearance is particularly unreliable in the story because Matèria Fosca warriors can adopt human form.

## Environment grammar

A world location should be capable of reading simultaneously as:

- place;
- organism;
- architecture;
- memory;
- dimensional interface.

This ambiguity is a feature, not a problem to eliminate.

## What to avoid

- glossy generic sci-fi;
- conventional fantasy ornament added without source evidence;
- neon cyberpunk palette;
- realistic military UI dominating the composition;
- procedural repetition without motif evidence;
- turning every symbolic form into a literal object;
- explanatory text overlays that destroy the visual mystery.

## Adaptation direction

The final game can add controlled color only where it communicates a world-state transition. The pencil edition should remain the canonical visual anchor; the colour/tridimensional edition is a useful secondary reference for possible volumetric treatment.
