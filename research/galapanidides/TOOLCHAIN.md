# GALAPANÍDIDES — Toolchain

## Active surfaces

- GitHub: canonical versioning and research records.
- Context7: current library/engine documentation and API verification.
- TinyFish: browser-based inspection of the public Chimelis Art site.
- Hot100.ai: discovery of external AI tooling; candidates only until evaluated.
- omgskills: discovery/evaluation of agent skills; read-only catalog.
- OGENIC GOD TOOLKIT: orchestration when a compatible execution surface is connected.
- ZzzOps: durable work/goal orchestration when initialized for this repository.
- Build Web Apps: auxiliary tooling around the project, not the Unity runtime.

## Engine

Unity 6.x + URP + Universal 2D / 2D Renderer.

## Current production rule

World rendering precedes gameplay mechanics.

## External tooling policy

Do not add an external skill, package, MCP bridge, or service solely because it appears in discovery. Evaluate compatibility, provenance, licensing, maintenance and actual utility first.

## Candidate skill notes

omgskills currently surfaces Unity-related skills and game-development workflows, including Unity terminal automation and broader game-development skills. These are candidates for a later local/Codex execution environment; they are not assumed to be installed here.

Hot100.ai provides a broad AI-project discovery layer. Current image-generation search surfaced image editing/upscaling/cleanup candidates, but none is adopted as canonical art production without testing against the pencil-source preservation requirement.

## Non-negotiable evidence boundary

Never report a Unity scene as rendered, tested or connected unless a real Unity project/editor execution surface returns evidence.
